# Skill Review

1. Read the SKILL.md in full.
2. Check: name is kebab-case and matches the folder; description says what it does AND when to use it; body is actionable steps, not prose.
3. Flag overlap with other skills in the library (`catalog/entries/`).
4. Report findings as a short list: issue, why, suggested fix. Do not rewrite unless asked.
